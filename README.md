# Rock of Hope Mission

A warm, responsive one-page NGO website revamp for Rock of Hope Mission Uganda, built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

The preview runs on port 3000. For a production build:

```bash
npm run build
```

## Content structure

The homepage presents the verified public content from `rockofhopeug.org` through the following sections: Who We Are, What We Do, Child Sponsorship, Child Protection, Economic Empowerment, Our Approach, Get Involved, and Contact.

The contact form is intentionally frontend-only in this first version. Connect it to the organization’s preferred email or form service before launch. The image assets in `public/images/` are visual research references for the prototype; replace them with approved Rock of Hope photography and confirm usage rights before going public.
